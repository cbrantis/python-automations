# Python Automation Projects

Projects built while learning Python automation and data engineering.

## Projects
- **etl-banks**: ETL pipeline that scrapes the largest banks list, converts market cap into multiple currencies, and loads it into CSV and SQLite. Built as part of the IBM Data Engineering course.
- **report-automation**: Script that downloads a sales file, calculates revenue and units sold with pandas, and emails a report. Built following Hashtag Treinamentos' automation challenge.

## Tech
Python, pandas, requests, BeautifulSoup, SQLite, PyAutoGUI
